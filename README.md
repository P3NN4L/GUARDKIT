# guard-kit —— 端内反诈引擎

**五引擎协同的端内反诈打分系统**：每条消息由主引擎 v8 蒸馏学生 + 雷达 v7 + SVM + NB 四个评分引擎独立打分、加权融合出最终判决，规则层（机构白名单三族）持否决权；裁判另提供回复质量评估。**零依赖、完全离线、单条消息 <0.1ms**，支持简体/繁体/粤语/英文，可嵌入任何 App——银行、社区、聊天、支付、教育。只输出风险概率与档位，不生成文本、不联网、不上传任何数据。

- 当前版本：`@p3nn4l/guard-kit@8.0.0`（五引擎系统；npm 包内含端内基座——雷达/裁判/规则层/多轮语境，主引擎 v8 权重经 Release 附件/热更新通道分发）
- 分发：GitHub Packages 私有注册表 + Release 附件（受邀访问，见[权限边界](#谁能看到什么权限边界)）
- 许可：**个人与非商业用途免费，商用需付费授权**（详见 [LICENSE](LICENSE.txt)）
- 本仓为接入文档与公开基准；不含引擎源码与权重原文

## 它能做什么

| 能力 | 说明 |
|---|---|
| 五引擎融合判决 | 四个异构评分引擎加权融合 + 规则层否决——单引擎的错误被席位吸收，对单模型时代 11 个评测集 10 胜 |
| 消息风险打分 | 单条短信/聊天消息给出校准概率与三档风险（高/中/低），档位阈值即误报率的产品语义 |
| 多轮语境检测 | 传入最近对话，铺垫句不误报，诈骗意图一出现即触发——并标注"结合上文判定" |
| 回复质量评估 | 对用户的回复给出四分类质量评级（简/繁/粤），用于反诈陪练等教育场景 |
| 机构白名单 | 合法机构通知（银行/政府/学校）三重条件识别，压低误报且零漏放（2,570+ 骗术样本 0 误放行） |
| 六端一致 | 同一份权重在 TS/原生 iOS/原生 Android/Flutter/小程序/云端输出逐位一致的分数 |

## 引擎内部（行为契约，不含实现）

接入方只需知道**输入输出与行为边界**，无需了解实现。以下为对外承诺：

**训练数据规模**：雷达 v7 训练语料 13,677 条（简繁粤英四语，HK 骗术家族 + LLM 蒸馏语料 + 多轮对话），另以 80 万条公开短信与 UCI 5,574 条做外部基准校准（heldout 锁定，永不入训）；v8 主引擎在此基础上叠加 6,628 条真实欺诈文本（10 类）与三教师（MiniLM/8B/多语言嵌入）软标签蒸馏。

**与 v7 的行为差异**：v7 对"换过说法的骗局"（不出现包裹/手续费/登录等关键词）存在盲区——一张换说法考卷上召回 71.4% 且误报 50%；v8 主引擎在同卷召回 100%、误报压到 12.5%（真实欺诈文本增强的功劳）。两者融合后：11 个评测集 v8 系统对 v7 单模 **10 胜**（对话卷误报归零），唯公开 120 条召回略让（78.2 vs 89.1，雷达席位以 0.3 权重留席补该域）。

**输入边界行为**：空串/纯英文单词等无词典命中输入 → 返回 0 分 + low 档（不抛异常）；超长消息 → 截断至 128 字符；emoji/增补平面字符 → 逐码点处理不错位；权重解析失败 → 构造时抛错（fail-fast）。引擎内部无任何网络/IO 调用。

**多轮语境机制**：传入最近对话数组，内部将最近 4 轮拼接评分与当前句单独评分**取最大值**——铺垫句（"在吗""吃饭没"）永远不触发，意图轮（"先转账""点链接"）一出现即触发，返回 `trigger='context'` 供 UI 标注。

**档位阈值即误报语义**：`high ≥0.75`（且原始证据 ≥0.505 双重确认）→ 建议拦截；`mid ≥0.35` → 提醒；阈值各端内置一致、不可调——要改误报率口径找我们发新版，不要宿主自己调。

**权重热更新**：主引擎权重为独立文件（不进安装包），经 Release 附件/CDN 分发——骗术进化后拉新权重即生效，宿主代码零改动。

## 安装与使用（TS / React Native / Expo / Node）

```bash
npm install @p3nn4l/guard-kit@8.0.0
```

```ts
import { mlScore, mlConversation, replyScore } from '@p3nn4l/guard-kit';

// 单条消息风险
const r = mlScore('【香港郵政】包裹已扣留，請登記：hkpost-redelivery.top');
// r.band → 'high' | 'medium' | 'low'（直接映射产品动作：拦截/提醒/静默）

// 多轮对话
mlConversation(messages);

// 回复质量（陪练/教育场景）
replyScore(reply);
```

只要风控不要陪练？装更小的雷达单包：`npm install @p3nn4l/guard-kit-radar`。需要回退旧版？`@6.2.0 / @6.1.0 / @6.0.0` 均在注册表。

## API 参考（TS，各端同构）

| API | 作用 | 返回 |
|---|---|---|
| `mlScore(text)` | 单条消息风险 | `{ pRaw, pCal, band, topType, probs }` |
| `mlConversation(messages)` | 多轮语境（最近 4 轮） | 同上 + `trigger: 'direct' \| 'context'` |
| `replyScore(reply)` | 回复质量四分类 | `{ topClass, confCal }` |
| `mlScoreV62()` / `mlScoreV6()`（`/legacy`） | 挂载旧代权重 | 各代同构 |
| `createRadar(json)` / `createReferee(json)` | 工厂函数，传入权重自建实例 | 引擎对象 |

## FAQ

**Q：需要联网吗？**
完全离线。零网络代码、零遥测，消息不出设备。

**Q：粤语/繁体/中英夹杂支持吗？**
原生支持。词表四语配额，训练语料含粤语多轮对话。

**Q：档位阈值要自己调吗？**
不。0.75/0.35 双条件档位在各端内置一致，阈值即误报率语义。

**Q：怎么商用？**
双档许可：个人与非商业用途（学习/研究/教学/竞赛/非商业项目）免费；商用联系 [github.com/P3NN4L](https://github.com/P3NN4L) 获取付费授权。权重不得单独用于训练其他模型。

**Q：有基准数据集吗？**
[HK-ScamBench](benchmark/HK-ScamBench.md)：12 个真实骗案家族 + 8 类机构通知，CC BY 4.0，可引用复测。
